Everything since v0.13.0:

- **Practice return zones** (M4-PRACTICE-03): a RETURN TO row on the
  PRACTICE page (ANY, KITCHEN, DEEP, LEFT LINE, RIGHT LINE). Only returns
  that land in the zone count toward the streak, each zone keeps its own
  best, and corner markers show the zone on the court.
- **The ball machine aims** (M4-PRACTICE-04): the nozzle turns toward each
  feed's lane before it fires, so you can read where the ball is going,
  and the machine kicks back as it feeds.
- **Fixes:** leaving practice for the park no longer drops a frame; the
  point banner draws over more frames in doubles.
- **Known issue:** doubles with all four modifiers on can drop a single
  frame as a point ends (KNOWN_ISSUES #22).
- **Saves:** your records, settings, and initials carry over (v0.4.0 and
  later saves), in a new layout with room for the practice zones.
